# leilao-api

Projeto NestJS (TypeScript, ESM).

## Comandos

```bash
npm install          # instala as dependências
npm run build        # compila para dist/
npm run start:prod   # inicia o servidor compilado (porta: variável PORT, padrão 3000)
npm run start:dev    # modo desenvolvimento (watch)
npm test             # testes unitários (Vitest)
npm run test:e2e     # testes end-to-end (Vitest + supertest)
npm run lint         # lint (oxlint)
```
